FlutterGuard 0.3.4 — the brand pass.

Same offline auditor, now wearing the flutterguard.dev family: porcelain and
forest surfaces, mint for the one thing that matters, flat ruled rows instead
of stacked cards. The app bar carries the launcher mark and a GitHub action.

- Light and dark schemes rebuilt from the site tokens, so the app and the
  landing page read as one product.
- Every card shell became a ruled row: inventory, report sections, findings,
  queue, banners and legal pages.
- Chips lost their outlines; selected state is the container plus a check.
- The search action is a solid forest button, and the search field owns its
  own surface instead of tinting the strip behind it.

Nothing changed in what a scan does: no network permission, no accounts, no
telemetry, reports stay on the device until you export or delete them.

Upgrading from the previous GitHub APK: this build uses a new signing key, so
Android will refuse to install it over 0.3.3. Export any reports you want to
keep, uninstall FlutterGuard, then install this APK. Uninstalling removes the
in-app reports, history and settings, and exports do not restore the history.
Play installs are re-signed by Google and are not affected by this change.
